# Claude Spend Bar

The download page for **Claude Spend Bar**, a macOS menu-bar readout of your
claude.ai usage.

**<https://tkachenkobogdan.github.io/claude-spend-bar/>**

This repository holds the page and nothing else. The app is released from
[TkachenkoBogdan/homebrew-tap](https://github.com/TkachenkoBogdan/homebrew-tap/releases),
which is also the Homebrew tap:

```
brew install --cask tkachenkobogdan/tap/claude-spend-bar
```
